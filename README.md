## 原生 IP 有什么用

AI 平台和流媒体判定你在哪个地区，靠的是**出口 IP 的归属**。原生 IP（看起来像普通住宅网络）比机房广播 IP 更不容易被判成代理——Claude、Netflix 这类风控严的服务尤其吃这一套。

官方标注 ChatGPT、Claude、Gemini 三家可用；Claude Code、Codex 未见标注，重度依赖的话先自测。
